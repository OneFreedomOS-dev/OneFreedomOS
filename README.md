## about

I built a kernel from scratch.  
OneFreedomOS is an operating system for x86 PCs — old and new.

No ARM. No Raspberry Pi. Just pure x86.

## stack

- **C** — kernel core  
- **Python** — GUI tools and scripts  
- **asm** — bootloader  
- **make / gcc / nasm** — build system
